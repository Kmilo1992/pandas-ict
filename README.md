# Pandas Movie Data Project

## Context
This project is designed for Grade 11 ICT, Unit 6: Data Analysis and Artificial Intelligence with Python.

Students progressively learn to:
1. Understand why AI uses data.
2. Understand what Pandas is.
3. Load a CSV dataset.
4. Explore a Pandas DataFrame.
5. Calculate descriptive statistics.
6. Interpret results as data analysts.

## Folder structure
- movies.csv -> the dataset used in all lessons.
- lesson_2_first_dataframe.py -> create a DataFrame manually.
- lesson_3_load_csv.py -> load movies.csv.
- lesson_4_explore_dataframe.py -> inspect the dataset.
- lesson_5_descriptive_statistics.py -> calculate statistics.
- lesson_6_movie_data_detective.py -> final student challenge.
- lesson_6_teacher_solution.py -> teacher solution for the challenge.
- teacher_notes.md -> step-by-step teacher explanation.

## Installation

First check Python:
    python --version

If that does not work on Windows, try:
    py --version

Then install Pandas:
    python -m pip install pandas

or, on Windows:
    py -m pip install pandas

If the computer has more than one Python installation, use the same Python command that successfully runs the scripts.

## Running a lesson

Open the project folder in VS Code and run the corresponding .py file.

Example:
    python lesson_3_load_csv.py

The CSV file must remain in the same folder as the Python file.
